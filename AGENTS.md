# Istruzioni per gli agenti AI

Prima di modificare il repository:

1. leggere README.md e la documentazione architetturale centrale;
2. rispettare i confini tra applicazioni, librerie e domini;
3. non modificare file generati;
4. aggiornare i test insieme al codice;
5. non eseguire commit o push senza esplicita autorizzazione.
